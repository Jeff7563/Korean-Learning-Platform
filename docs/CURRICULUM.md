# Curriculum V0.1

## Phase 1: Hangul Foundation

1. Introduction to Hangul
2. Basic Korean Vowels
3. Basic Korean Consonants
4. Combining Consonants and Vowels
5. Additional Vowels
6. Double and Aspirated Consonants
7. Korean Syllable Blocks
8. Introduction to Final Consonants (Batchim)
9. Beginner Reading Practice
10. Hangul Foundation Review

Each authored lesson has Thai explanations, objectives, examples, vocabulary, activities and five multiple-choice questions. Passing threshold is 80%. Checklist completion is separate from passing a checkpoint.

## Planned phases

Everyday Korean, Korean Grammar, Workplace Korean and EPS-TOPIK Preparation are visible as planned phases with no fabricated lessons.
